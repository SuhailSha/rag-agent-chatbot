# Enterprise RAG Multi-Agent Chatbot System

A production-grade, modular RAG (Retrieval-Augmented Generation) document management platform with an autonomous multi-task agent orchestration layer.

## Setup & Execution

### 1. Installation
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Configuration
Copy `.env.example` to `.env` and configure your API keys (optional for local mock/heuristic mode):
```env
OPENAI_API_KEY=your_key_here
CHROMA_PERSIST_DIRECTORY=./chroma_data
CHUNK_SIZE=400
CHUNK_OVERLAP=40
```

### 3. Launch Backend
```bash
python3 main.py
```
Access the interactive Swagger API documentation at: `http://localhost:8000/docs`

## Core Endpoints
- `GET /api/documents`: List all ingested documents and their chunk metadata.
- `POST /api/documents/upload`: Upload, chunk, and index a new file.
- `DELETE /api/documents/{doc_id}`: Remove a document and unindex its vector chunks.
- `POST /api/chat`: Send a prompt to the multi-agent orchestrator.
- `GET /api/tasks`: List all automated action items and tasks generated by agents.
